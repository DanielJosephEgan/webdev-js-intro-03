#1 Explain why a number data type added to a string data type returns a string.
  A: When a number data type is added to a string data type, the result is a string because most programming languages automatically convert the number to a string before performing string concatenation (joining the characters together) when the "+" operator is used with a string involved, effectively treating the operation as a string manipulation rather than a mathematical addition.

#4 Explain a situation where you would use the Modulus operator and why.
  A: You would use the modulus operator ("%") in programming to find the remainder of a division operation, which is particularly useful when you need to check if a number is divisible by another number, perform operations on a repeating cycle (like every "n" iterations in a loop), or extract specific digits from a number based on a positional system (like getting the last digit of an integer).
